V4 Studio embed (mode: widget-v4)

Config must exist before reih-widget.js runs (see script order below). Open DevTools → Console; on success you should see reihwidget:ready with detail.mode === "widget-v4".

  1. From repo root run npm run build.
  2. Serve the repo root (e.g. npx serve . -l 3333) and open this page.
  3. If nothing appears, confirm script order and that #reih-widget-host exists in the DOM.
