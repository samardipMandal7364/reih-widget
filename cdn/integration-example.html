REimagineHome Widget — Integration Demo

This page demonstrates the widget running via iframe CDN. Look at the bottom-right corner for the chat FAB.

Note: Replace YOUR_CDN_URL with the actual URL where you deploy the cdn/ folder.

Integration Code

<script>
  window.reihWidgetConfig = {
    tenantId: 'YOUR_TENANT_ID',
    mode: 'chat',              // 'chat' | 'restyle' | 'widget-v4'
    embedBaseUrl: 'http://localhost:4000'  // where embed.html is hosted
  };
</script>
<script src="http://localhost:4000/reih-loader.js" async></script>
